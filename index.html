First pull in: what the analyzer is

analyze-dns-analyzer examines DNS traffic for suspicious patterns, naming two patterns outright: domain generation algorithms and fast flux DNS.

Data analysis and reporting. That is the focus the README gives, and this stop adds no wider promise about blocking traffic or live defence.
